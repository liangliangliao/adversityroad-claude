# 逆境之路 AdversityRoad

Unity 第三人称动作冒险 RPG：把现实中的困境转译为可战斗、可识别、可反击、可成长的敌人与场景。

> 看见弱点 → 面对困境 → 主动战斗 → 失败复盘 → 强化意志 → 再次挑战 → 逆袭成长

- 引擎：Unity 6000.5（URP，安卓/PC 双端）
- 打包：GitHub Actions + game-ci/unity-builder（推送到 `main` 或 `claude/**` 分支自动构建安卓 APK，Library 已缓存）

### 方案对齐 · 四大新关卡（本次迭代）

按最终商业化方案把 Demo 四关一 Boss 补齐成型：

- **小题大做审判庭（方案关卡一）**：倾斜的法官席 + 两侧旁观者席阴影；6 枚**浮动标签**
  （"太敏感/小题大做/你也有问题"……）悬浮在通道上空，用兵器击碎回补自尊、降低反刍；
  **证据桌**走近即"看清事实"——此后标签一击即碎（事实先于评价）；**破碎镜子**回补自尊。
  Boss【自我否定法槌】三阶段：**标签弹幕 → 审判冲击波（大红圈预警）→ 自我否定重锤（追身落锤）**；
  二阶段起触发**围攻审判**（旁观席召唤旁观嘲笑者），重锤落地后**法槌裂缝显现**=短暂破绽窗口
- **噪声放大（方案关卡二 Boss）**：回到噪声街区，街心广场上的【刺激放大器】——
  街道新增**噪声区**（广告牌下/公交站旁：站入专注缓慢流失，定心姿态减免、不读心盾免疫，影响很轻防晕）；
  周期性**噪声放大**（全场专注冲击，定心格挡/不读心盾可整个化解）；制造**幻影假目标**
  （攻击幻影=把力气花在猜测上：掉专注、涨反刍）——「不读心盾」使幻影显形消散、
  「注意力回收」全场清除后猛攻真身
- **拖延沼泽（方案关卡三）**：主入口在**噪声街区尽头东南侧**（第九章开启的一瞬门就解锁，
  全链路不再有"提前出现的锁死门"）；浅泥轻减速/深泥重减速+行动力流失、**干地平台**落脚、
  **手机光点区**（站入即流失专注与行动力）、**目标石板**（站上恢复行动力）、床铺藤蔓与漂浮计划纸。
  Boss【明天之王】**泥壳护体**（伤害大减打不动）——点燃场边**三座五分钟火种台**（走近即点燃）
  泥壳崩裂进入长破绽；战斗中召唤明日泥怪、往玩家脚下浇灌临时深泥
- **旧事回声馆（方案 Demo Boss·旧我回声）**：博物馆展柜长廊——靠近展柜触发**旧事回声**（反刍上升），
  站定完成**归档**（看见事实→命名感受→提取边界→转化行动），归档 3 座开启终局大门；
  失败展廊有旧话复读者/过去判官/反刍虫群把守。终局 Boss【旧我】四阶段：
  **旧话复读 → 身份冻结（「五分钟火种」解冻）→ 失败召回（召唤前章旧敌幻影）→ 整合选择**——
  残血后旧我停手且无法再被攻击（血线保护），走进**整合圆环**完成「旧我整合式」：
  **旧我化为影子护卫**随行（永久保存，靠近时反刍消退加速）。
  核心台词：「你曾经保护过我，但现在我要继续往前。」

### 战斗系统（借鉴黑神话悟空框架）

- **双系连段（招式全部绑定 Mixamo 动作库真实动作）**：
  拳=巨剑连斩「巨剑横斩→巨剑撩斩→突刺→巨剑旋风斩」，腿=腿法连段「正踢→侧踹→旋身空翻踢→飞踢」，
  两系可自由混接；动画从发力相位起播+提速播放，命中后即开取消窗口——连点无缝衔接不糊招
- **组合招式（连点拳/腿按序自动成招）**：拳拳拳=三连斩·大回旋、腿腿腿=三连腿·裂空飞踢、
  拳拳腿=双斩·空翻旋踢、腿腿拳=双腿·贯心突刺；2 势绝招：拳拳腿腿=龙卷·旋风绝斩、
  腿腿拳拳=踏空·裂地跳劈、拳腿拳腿=剑影·惊鸿飞踢（终结动作均取动作库大招）
- **摇杆磁吸锁敌**：攻击范围内有敌人即自动咬住目标出招（摇杆用于多敌间选目标、或明确指空处脱离），
  磁吸突进差多远冲多远，连点每一击都实打实命中
- **意势系统**（棍势式资源，0-3 点）：命中轻击/完美闪避/蓄力积攒，HUD 圆点显示，满势脚下亮起光环
- **蓄力重击**：按住「重」沉腰举械蓄力（耗体力、积意势），松开释放**蓄力·巨剑跳劈**；
  **势≥2 触发旋风终结**（消耗全部意势大幅增伤）；连段中轻点「重」派生**切手·撩斩**快速反击；
  指令技（轻点重+方向）：前=疾影突刺、后=旋身空翻踢、左右=旋风斩；跳中按重=空袭·裂地跳劈
- **完美闪避**：在敌人攻击命中瞬间翻滚 → 短暂时缓 + 意势+1 + 下一击必暴击（敌人攻击带 0.28s 前摇可读招）
- **空中攻击**：跳+拳=空袭跳劈、跳+腿=飞踢、跳+重=空袭·裂地跳劈；
  **蹲伏攻击**：蹲+腿=扫堂腿（贴地环扫、高削韧）、蹲+拳=低位突刺（下段直线戳击）
- **每招独立攻击范围**（长/宽/高/轨迹各不相同，技能越高范围越大）：突刺长而窄（直线）、
  横斩横宽（横扫弧）、撩斩纵高、旋风斩/扫堂腿环身 360°、跳劈罩住落点；
  蓄力越满范围越大，绝招终结与技能级攻击范围最大
- **双角色 + 武器库 + 面具库（角色/武器/面具三者资产分离，内置 glTFast 支持 glb/gltf）**：
  「角色」面板先选角色（角色·贰=`PlayerModel2`，glb/gltf/fbx 均可、动作沿用角色壹动作库、
  缺失自动回退；**异源骨架自动对齐**——glb 角色骨名无 mixamorig 前缀/层级不同时自动改名
  与链路对齐，默认动作库直接可用），再从武器库（`Characters/Weapons/`，glb/fbx/gltf/zip）
  选武器——默认持剑（模型无自带兵器时程序化长剑兜底），重选即替换：**握持对齐+手指握拳**
  （复刻角色壹自带巨剑的世界空间握姿、柄端入掌心、五指绕柄轴卷曲攥住剑柄）；
  再从面具库（`Characters/Masks/`，fbx/glb/gltf/zip）选面具戴脸——自动定尺贴脸、随头骨转动，
  支持多面具切换；三者选择均本地持久化。动作库补位：放入 Blocking/Stand To Roll/Stunned/
  Great Sword Casting/Leg Sweep 等专用片段即自动替换现有替代动作（见 MIXAMO_SETUP.md）
- 格挡（边界盾）/ 精准格挡（定心格挡化解心理攻击）；锁定与互动全自动化（无需按键）
- **战斗可读性（对标商业动作游戏的产品化打磨）**：
  - **近镜角色淡出**：镜头贴近任何角色（近身缠斗/贴墙）时该角色整体淡为半透明，
    根治"整屏被模型糊脸/镜头穿模"；镜头碰撞回缩下限抬高，不再缩进身体
  - **角色保持原色**：玩家与敌人均不做整体染色，保留模型原本材质与肤色；
    敌我识别交给头顶状态条、前摇红圈与恶意台词
  - **屏幕固定连击计数器**（格斗游戏惯例）：连击数固定在屏幕右侧弹缩显示、越高越红、断连淡出，
    不再跟着命中点满场乱飞；招式名浮字节流（同名招 0.9s 内不重复弹），战斗信息不刷屏
  - **夜战保底亮度**：夜晚/暗场景环境光与主光下限上调，看清双方拳脚与前摇优先于氛围
- **部位受击反应**：按命中点定位身体部位（头/躯干/腰腹/左右腿），被打部位向打击方向甩动回弹
  （打头甩头、扫腿屈膝），接触点弹出部位标签；冲量可叠加——连打两下头就有两次可见甩头；
  重击倒地为「当场栽倒」：受击位移只在身体后仰头几帧内完成，全程零漂移滑行
- **战斗反馈**：伤害数字、受击闪红、碎块飞溅、顿帧、震屏、程序化动作姿态（前倾挥击/翻滚/倒地/僵直/施法/死亡倒伏消散）；
  **程序化音效**（零外部资产，运行时 PCM 合成）——挥击风声/命中闷响/重击/格挡/定心弹反/前摇警示/受击/死亡各有其声；
  刀光改为细窄半透明加色的一道光（非大色块），绝招/组合技为「能量光爆」（强闪光+放射光条+上升火星+细冲击环）而非平铺色板
- **招式分工**：拳=快攻（出手快、低击退、高频衔接），腿=击退（大幅推开、打断突进），重击=破防（高削韧击破霸体），
  防御=减伤（体力格挡免伤 80%），闪避=反击（完美闪避时缓+返势+必暴击），意志技/定心格挡=反制心理攻击
- **重击倒地**：高伤害攻击将玩家击倒，倒地演出 + 起身无敌帧
- **敌人头顶状态条**：名字+等级、血条、韧性条、实时情绪（窥伺/紧逼/狰狞/讥讽/慌乱）

### 心理攻击（语言+情绪层面）

### 防晕设计（镜头/帧率/后处理/移动）

- **帧率**：安卓默认 30 帧已解锁——目标帧率取屏幕刷新率（60–120），并启用 Frame Pacing（Swappy）稳定帧间隔
- **镜头**：跟随点为平滑 CameraTarget（水平/纵向均临界阻尼软跟随，极短时间几乎无滞后又滤掉逐帧
  移动微抖动，消除晃屏与橡皮筋游动感），转角临界阻尼平滑无过冲，FOV 固定 62° 永不变化，
  碰撞回缩快伸出慢不弹跳，震屏改为极小纵向脉冲（无随机抖动），专注低不再摇镜头（改由暗角表达）
- **三模式运镜（角色转向快 / 位置中速跟随 / 镜头旋转慢）**：
  - **探索镜头**（无敌）：位置用中速 `SmoothDamp` 跟住玩家、角度基本固定；**玩家一转向，
    镜头即刻开始平稳缓慢地转到其背后（面朝方向）**——用大平滑时间的临界阻尼弹簧，转身即跟、
    小抖动只带来极轻微慢移不晃屏；树木/建筑遮挡自动透明
  - **战斗镜头**（锁定敌人）：镜头优先看敌人，取景点偏向「玩家↔敌人中点」让**两人同框居中**、
    压低俯仰、适度拉近看清拳脚与前摇；攻击自动朝向敌人，可轻微围敌调整但不乱晃
  - **大招镜头**（仅超必杀触发）：短暂拉近 + 轻微慢动作 + 命中小震，结束自动回稳；
    **普通移动/普通攻击都不会触发这种镜头，普攻也不再频繁震屏**（防晕）
  - **第一人称**：镜头在眼睛高度、脸前方，俯仰自由——低头看见自己的手/脚/剑，抬头看见天空，
    挥剑/踢腿低头即见肢体与兵器在空中运动；只隐藏头部，身体其余可见
  - 底层：转角/位置均临界阻尼平滑无过冲
- **遮挡自动透明**：树木（含无碰撞体的树冠）挡在镜头与玩家之间时自动淡出为半透明，移开即淡回
- **移动**：加减速平滑（速度无突变），摇杆全向 360° 模拟量走跑（极小死区仅滤静止噪声）；
  人形步态叠加脊柱反向扭转/躯干侧倾/骨盆侧摆/落步点头等次要动作，消除机械感
- **后处理**：运行时强制关闭运动模糊/色差/镜头畸变/噪点，暗角强度限幅

### 言语攻防 · 反刍 · 战后复盘（本次迭代）

把方案里最核心的循环——「语言打语言、事实打赖账、边界打索取、不读心打刺激、复盘代替反刍」——落成可玩机制：

- **言语攻防（快速选择式）**：敌人发动心理攻击（凝视/低语）时，屏幕下方弹出**三选一回应**面板
  （一句「最优回击」+ 两句「无效回应」，随机打乱，5 秒倒计时，战斗不暂停用非缩放时间计时）。
  - **选对**：敌人**语塞进入破绽**（削韧，可击破触发大破绽）、对应弱点属性回补、反刍下降，**且不吃这次心理伤害**
  - **选错/沉默**：照常吃心理伤害，并**额外累积反刍**（互骂/退缩/过度辩护只是把自己拖进反刍）
  - 回应库按弱点轴给出最优句（如噪声轴「我听见了，但我不跟随」、边界轴「帮助有边界，这次你自己承担」、
    求职轴「没有回应不代表没有价值，我再来一次」），全部抽象化、服务战斗机制，绝不输出现实操控话术
  - 冷却/恢复模式/已在进行时自动回退为原来的即时落伤害
- **内部言语攻击（脑内回声·本次迭代）**：方案的「内心敌人字幕攻击」落地——
  言语攻防不只来自外部敌人，也来自玩家**自己的脑内回声**。反刍累积到 ≥55%
  （或场上有 `Internal` 类内心敌人逼近且反刍 ≥35%）时，第一人称的负面念头浮出
  （「我是不是根本不行？」「万一又失败了呢？」「明天再开始也一样」），用同一套
  三选一言语攻防回应：**答对**→脑内回声散去、反刍下降、对应属性回补；
  **忽略/答错**→照常吃心理伤害并额外累积反刍（越回避越回放）。反刍越高、内心
  敌人在场，触发越频繁；与外部言语攻防、休养生息答题互斥（同一时刻只弹一个模态）
- **反刍值（方向相反的消耗条）**：越满越糟。被心理攻击命中即累积，选错回应额外增加；
  战斗外缓慢消退避免软锁；上升时紫色暗角脉冲提示
- **行动力 ActionPower（本次迭代·替代"决断"）**：拖延轴攻击/深泥/手机光点消耗它，
  **过低时移速明显下降**（拖延的具象体感）；五分钟火种/火种台/目标石板恢复
- **关系消耗值 RelationshipDrain（本次迭代·第二条反向消耗条）**：被索取/责任转嫁类攻击、
  接下虚假责任时上升；**≥70 时技能冷却 ×1.5**（被掏空的注意力与精力）；
  守住边界的正确回应与边界圈使其回落，战斗外缓慢消退
- **战后复盘（安全屋核心·「复盘」面板）**：把这一战整理成**四栏——事实 / 感受 / 边界 / 行动**
  （按当前章节主题生成，抽象化不复刻真实人物/事件）；**「归档此战」清空反刍值并回补心理属性**——
  用复盘把刺痛转成经验，旧事进入档案不再无限回放
- **失败诊断与失败档案（方案"失败即复盘的起点"落地）**：倒下时不再只有一句通用话——
  按死亡时的**心理数值轴**（意志/专注/自尊/边界/反刍/体力）给出**个性化诊断 + 针对性策略**，
  并归因到**致死心魔**；重复败给同一心魔会**逐步升级引导**（第 3 次起指向「图鉴」破解）。
  诊断作为**复盘种子**在再战后预填「复盘」面板的感受/行动两栏；「档案」面板顶部新增
  **失败洞察**（累计倒下 / 最常败给谁 / 明细）——失败是事实，不是身份，你每次都站了起来
- **失败展览馆·个人化联动**：旧我线「失败展览馆」的展品**动态取自你真实的失败记录**——
  每件展品裱着你败给过的心魔与次数、配可读铭牌；走近展品触发**重构台词**

  （失败没资格坐上"定义你是谁"的位置）。无失败记录时退回通用主题展品

### 公平刺痛值 FairnessPain（本次迭代 · 补齐方案「十七、核心数值系统」）

方案核心数值里的**公平刺痛值**此前缺失（公平轴攻击错误地扣到边界值上），现补齐为独立属性：

- **上升**：遇到赖账、毁约、小题大做等不公平攻击（公平轴心念弹/近战）时累积——越高越糟；
  战斗外缓慢平复（比反刍更慢）
- **三档规则**（严格对齐方案）：
  - **0-30 清明区**：记住事实、不被困住——事实系物理输出 ×1.12；
  - **31-70 激愤区**：攻击上升（×1.08），但代价是**反刍累积风险 +50%**；
  - **71-100 失控区**：愤怒让判断下降——物理输出 ×0.9、**一切心理伤害吃得更重（×1.25）**，失控瞬间字幕警示
- **回落**：用事实回应不公（言语攻防答对该轴）主降刺痛并回补边界；**战后复盘归档**一并清零；

### 能量动态与分级警告（本次迭代）

心理能量不再"只有 HP 在动"——战斗行为本身驱动全部能量条起伏（`MentalDynamics`）：

- **生命垂危决策**：生命 <25% 红色罩屏脉冲随伤势加深；**<15% 弹出「生命垂危」模态弹窗**——

- **垂危警告保证送达（事件驱动）**：掉血**穿越垂危线的瞬间**立即触发弹窗（不依赖每帧轮询，

### 与官方/开源参考的参数核对（本次迭代）

对照 [Unity 官方 ThirdPersonController](https://github.com/nrsharip/unity-third-person/blob/main/Assets/StarterAssets/ThirdPersonController/Scripts/ThirdPersonController.cs)
与 [UE SpringArm 官方示例](https://dev.epicgames.com/documentation/unreal-engine/using-spring-arm-components?application_version=4.27)
逐项归一化核对，结论是**本项目数值本就在标准区间内**：

| 项目 | 本项目 | 官方参考 | 判定 |
| --- | --- | --- | --- |
| 跑速 | 5.2 m/s | Unity 5.335 m/s | 几乎一致 |
| 走速 | 2.6 m/s | Unity 2.0 m/s | 同量级 |
| 重力 | −20 | Unity −15 | 略重（动作向） |
| 角色转向时间常数 | 0.071s | Unity RotationSmoothTime 0.12s | 更跟手（战斗向） |
| 土狼时间 | 0.12s | Unity FallTimeout 0.15s | 同量级 |
| 镜头吊杆长度 | 4.76 m | UE SpringArm 3–4 m | 更长＝视野更开阔 |
| 镜头位置跟随 | 0.09s | UE CameraLagSpeed 3.0 → 0.33s | 远比 UE 跟手 |
| 视野 | 垂直 56°（@16:9 ≈ 水平 87°） | UE 第三人称模板 水平 90° | 不算窄 |

**这一核对本身就是结论**：此前所有卡顿/盲区/不连贯问题，根因都是**结构性缺陷**
（体力静默中断连段、互斥分支漏掉中幅转向、消费式输入互抢、镜头意图模型错误），
而不是数值不对——所以"照抄别家参数"解决不了，必须逐个定位逻辑。

**唯一有实据可改进的一处已采纳**：Unity 官方用**指数逼近**做加减速
（其注释原文：*curved result rather than a linear one giving a more organic speed change*），
本项目原为线性匀加速（`MoveTowards`）。已改为 `1−e^(−k·dt)` 指数逼近（帧率无关）：
起步 k=20（0.05s 到 63%、0.15s 到 95%）、刹车 k=26——起步瞬间给足冲量更跟手，
末段自然收敛不突兀。

### 镜头意图识别（本次迭代 · 「面壁转身看正脸却被甩向墙面」）

实测反馈：**面前是墙、用摇杆转身想看清角色的脸，镜头却立刻绕开去看墙面。**
这不是参数问题——是镜头的**意图模型**错了：它假设「玩家永远想看角色的正前方」，
于是把一切转身都读作"要换行进方向"。补上两层意图识别：

**① 区分「转身看一眼」与「真要往那个方向去」**

角色朝镜头走来（偏差≈180°）时，此前一律绕到背后。改为按**是否持续行进**判定：

| 玩家行为 | 镜头 |
| --- | --- |
| 短暂转身看正脸 / 贴墙后退调整站位 | **岿然不动**——看得到正脸，视野不塌 |
| 持续朝镜头方向跑 **>0.9s** | 缓缓绕过去——角色不会跑出画面 |
| 战斗中转身打背后的敌人 | **豁免**，仍快速追击（看见敌人优先） |

**② 不把镜头甩进墙里**

大幅回正前先**探测目标方位的空间**（与主碰撞同一套过滤规则）：越憋屈转得越慢
（最低降到 **25%**）。面壁转身时"绕到角色背后"恰好是墙的方向，硬绕过去只会让镜头
顶在墙上被迫贴脸、视野瞬间塌掉——现在会把镜头留在看得见的地方。

**③ 手动取景保护 0.3s → 1.2s**：玩家刚手动摆好角度，镜头 0.3 秒后就自己转回去，
读作"和我抢镜头"；1.2s 让手动取景有足够停留时间。

### 镜头同步跟随统一化（本次迭代 · 转向尺度 → 镜头幅度）

目标：**转向/移动幅度越大，镜头同步调整越快；任何情形下都不留盲区。**
核查发现此前的实现还有两个覆盖缺口：

- **战斗中 12°–55° 的中幅转向完全没有跟随**——战斗与探索是互斥的 `if / else if`
  两条分支，`InCombat` 为真时只走战斗分支（需 >55° 才启动），中等幅度转向被两边都漏掉，
  这是战斗中长期存在的**部分盲区**
- **技能/出招期间推杆转向不跟随**——出招时角色被"定步"锁住只转不移动，
  `moveSpeed≈0` 被判定为静止，回正条件不成立

改为**一条统一的渐进跟随曲线**（无分档断层）：

| 情形 | 行为 |
| --- | --- |
| 中小幅转向（>10°）+ 有移动**或推杆** | 温和跟随，偏差越大越快 |
| 大幅换向（战斗 >55° / 探索 >45°） | 迟滞开关锁定追击，直到 <12° 才松开 |
| 站立不动且未推杆 | 完全不动（无漂移） |
| 手动转镜期间 | 一律让位给玩家 |

- 角速度按偏差**连续映射**：平滑时间 0.5s→0.15s、转速上限 **70→340°/s**——
  小幅修正慢而稳（防抖），大角度掉头迅速跟上（防盲区），两者不再互相牺牲
- **「正在推杆」也计入主动意图**：覆盖出招/技能中的转向，角色转到哪镜头跟到哪
- **视野开阔化**：疾跑与大幅转向各给一点点拉远（合计 ≤ +12%，变焦极慢）——
  转身掉头的瞬间正是最需要看清周围的时刻，给"要去的方向"留出可见余量

### 连打不再卡顿（本次迭代 · 体力静默中断连段）

实测反馈「连续快速按拳/剑/重/绝招/技能仍会明显停顿；同时推着摇杆更明显」。
算一笔账就找到了元凶——**不是延迟问题，是招根本没打出来**：

| | 数值 |
| --- | --- |
| 轻击连打频率 | ≈ 5.8 段/秒 |
| 体力消耗（旧：每段 8） | **47/秒** |
| 体力回复（旧） | 15/秒 |
| 结果 | 满体力 100 点 **连打 3.2 秒即见底**，之后每次出招 `SpendStamina` 失败 → 静默 `EndCombo` → **人站在原地不动**，每 0.53 秒才憋出一招 |

- **连段永不被体力静默中断**（核心修正）：体力不足时**照常出招**，改为进入「疲惫」——
  伤害 ×0.6、不积意势，并给节流提示。大作的原则是"打得动但没力气"，
  体力只影响**强度**，不影响**能否出招**——连打的手感必须永远连续
- **体力经济重平衡**：轻击 8→**3**、回复 15→**22/秒** → 连打净值 **−4/秒，可无限连打不见底**；
  体力的真实取舍回到闪避/蓄力这些「大动作」上
- **推杆时更明显的原因**：出招瞬间移动速度被**硬性砍到 10%**、收招瞬间弹回全速，
  配合已提速的加减速（0.09s 刹停）形成**速度震荡**，读作一顿一顿的抽搐。
  改为对倍率本身做 ≈0.07s 平滑过渡、下限抬到 0.3——既保留定步分量感，
  又让「边推杆边连打」是一条连续的速度曲线
- **技能侧**：仅在「出招锁定」时才排队重试（冷却/资源不足不入缓冲，避免每帧重试刷屏）；
  冷却与资源不足提示加节流；体力/意志不足从**静默失败**改为明确反馈

### 意图匹配：输入保真度（本次迭代 · 「人机合一」的底层）

实测反馈「对移动、动作、转向的控制不够精细灵敏，希望角色与玩家意图完全匹配」。
这类"隔了一层"的体感，根源不是速度不够快，而是**玩家按下的键没有被完整兑现**。
按大作的输入保真度标准补齐三层：

**① 通用输入缓冲 `InputBuffer`（核心）**
玩家在硬直、翻滚、出招锁定等**暂时无法响应**的窗口里按下的键，此前被整帧丢弃——
真实意图是「我现在就要闪」，却被系统读成「你按早了，重按」。现在一律记录时间戳暂存，
**恢复可控的第一帧立刻兑现**；超窗作废（防陈旧输入迟到触发）：

| 动作 | 缓冲窗 | 解决的具体问题 |
| --- | --- | --- |
| 闪避 | 0.30s | 硬直中/翻滚中按闪没反应；**连续翻滚失效** |
| 跳跃 | 0.20s | 落地前一瞬按跳被吞 |
| 技能 | 0.35s | 出招锁定中按技能石沉大海 |

- **土狼时间 0.12s**：离开平台边缘后仍可起跳——意图是"我在边缘按了跳"，不是"晚了两帧活该掉下去"
- **修复消费式输入互抢**：`MobileInput.GetDown` 每帧只能被读一次，此前 `PlayerController`
  与 `PlayerCombatController`（受身）各读一遍 `Dodge`，谁先执行谁拿到——
  **倒地时按闪常常没反应正是这个原因**。现在全局唯一消费点 + 共享缓冲（已加不变量校验）
- **修复缓冲采集时机**：输入采集原在翻滚 early-return **之后**，翻滚中的按键整帧跳过；
  已移到所有 early-return 之前

**② 移动响应提速（起步不再拖沓）**

| 项目 | 调优前 | 调优后 | 大作标准 |
| --- | --- | --- | --- |
| 0 → 全速 | 0.29s | **0.12s** | 0.08–0.15s |
| 全速 → 停止 | 0.20s | **0.09s** | ~0.10s |

防晕改由**镜头侧**负责（软跟随 + 焦点死区 + 渐进回正），而不是靠拖慢角色本体——
这是主流第三人称动作游戏的正确分工：**角色跟手，镜头稳定**。

**③ 已有的保真基础**（本次核对确认到位）：虚拟摇杆 0.06 径向死区 + 死区外重映射 0–1 +
响应曲线（小幅推杆＝精细慢走）；攻击输入缓冲 0.6s；全部旋转/位移基于 `dt` 帧率无关。

### 出招转向影响（本次迭代 · 「出招 + 推杆转向」不连贯）

实测反馈「做动作/技能/绝招同时推摇杆改变方向时不连贯、不连续」。查出三处叠加成因：

- **技能/绝招/重击期间摇杆完全无响应（主因）**：`IsHardLocked` 分支直接 `return`，
  整个 1.15–1.45 秒的技能连招里推杆毫无反馈，动作结束才**突然弹到**新朝向——
  这正是"断裂感"的来源。改为大作通用的 **attack steering（出招转向影响）**：
  硬锁动作期间仍可用摇杆调整朝向，按状态给不同角速度上限——
  技能/绝招 **110°/s**、重击/蓄力 **85°/s**（最重、转向最慢）；
  **受击/倒地/心理硬直/死亡不给转向**（挨打就该失控，这是打击反馈的一部分）
- **轻击连段转向被过度阻尼**：旧值 `Slerp(rate 2.2)` 每帧只挪 3.7%，推杆几乎转不动，
  读作"一出招就僵住"。改为明确角速度上限 **150°/s**——既能顺着摇杆把连招引向新方向，
  又不会一帧甩离当前目标
- **技能每段硬吸附覆盖玩家意图**：连招每段 `FaceTarget()` 瞬时锁向自动目标。
  改为**玩家意图优先**——推杆幅度足够且方向与目标偏差 >45° 时顺着摇杆出招，
  连招跟着你走；否则才咬住自动目标
- 摇杆输入统一在帧首读取一次，供出招转向与移动共用（消除重复计算）

### 转身盲区修复（本次迭代 · 视野变窄/看不见前方）

实测反馈「改变方向/转身时视野变狭窄、处于盲区」。定位到**两个独立成因**并分别修正：

**成因一：镜头开始回正前的等待过长（主因）**
上一轮防抖调优引入的低通滤波（固定 0.2s 收敛）+ 稳定计时门槛（0.22s）叠加，
转身后镜头要等约 **0.42 秒**才开始跟——这段时间你朝新方向走却看不见前方。修正：

- **自适应低通**：朝向还在乱动时收敛慢（滤掉摇杆抖动），一旦稳定就快速收敛（5→18/s）
- **门槛收短**：探索 0.22→0.15s、战斗 0.35→0.24s（快速搓杆仍永远攒不满，抗抖不变）
- **慢速移动也回正**：阈值 1.4→0.6 m/s——蹲行、走路、出招定步此前**完全不回正**，
  在这些状态下转身等于永久盲区
- 综合：开始回正前的等待 **0.42s → 0.21s**

**成因二：渐进式回正（小角度稳、大角度快）**
固定 85°/s 的封顶让大角度掉头追得慢。改为按偏差插值——
探索 0.5s/70°/s → 0.16s/300°/s，战斗 0.28s/180°/s → 0.15s/340°/s：
180° 掉头完全归位 **1.23s → 0.90s**，而 20° 小幅修正仍保持平缓（0.83s），抗抖不受影响

**成因三：转身时吊杆扫过墙体被拉近 → 画面贴脸变窄**

- 碰撞探测球 0.25→**0.18**：擦过墙角/柱子不再误触发大幅回缩
- 回缩下限 1.35→**1.6m**：即使贴墙也保留可用景别
- **伸出恢复 0.3→0.14s**：扫过障碍后视野立刻回到正常景别，不再长时间贴脸发窄
  （回缩仍保持 0.03s 的快速响应，避免穿墙）

### 战斗提速调优（本次迭代 · 对照大作帧数据标准）

实测反馈「动作/技能/绝招攻击速度很慢」——对照主流动作游戏帧数据做了一轮系统调优：

| 项目 | 调优前 | 调优后 | 大作标准 |
| --- | --- | --- | --- |
| 轻击起手 / 取消窗 | 0.07 / 0.20s | 0.05 / 0.155s | 0.05–0.13 / 0.13–0.18s |
| 轻击全长（拳系） | 0.40s | 0.30s | 0.25–0.35s |
| 剑系末段旋风斩 | 0.60s | 0.46s | 0.4–0.5s |
| 成招终结窗口 | 0.68s | 0.50s | 0.45–0.55s |
| **技能动作锁** | **1.7–2.2s** | **1.15–1.45s** | **0.8–1.4s** |
| 超必杀「觉醒·乱舞」 | 2.2s | 1.75s | 1.5–2.0s |
| 蓄力满 / 二连间隔 | 1.2 / 0.5s | 0.85 / 0.34s | 0.7–1.0 / 0.3–0.4s |
| 指令技冷却 | 3.5s | 2.2s | 1.5–2.5s |

- **收招闪避取消（AAA 核心手感·新增）**：技能/绝招/蓄力二连演完主要打击段、进入**恢复相位**后
  可用**闪避立刻打断收招**——不必干等动作播完，攻防转换一气呵成。这是"卡手感"的最大来源，
  也是大作（DMC/战神/只狼）通用的 dodge-cancel 规则；任何状态切换自动复位，不会误放行
- **攻击动画同步提速 ~15%**（1.4–1.7× → 1.55–1.95×）：逻辑窗口收紧后动画必须跟上，
  否则挥击相位演不完就被下一段切掉——动作依然完整，只是更"脆快"
- 闪避输入改为**每帧统一读取一次**，供收招取消与常规翻滚共用，杜绝消费式输入被读两次而丢键

### 大作级近战规则（本次迭代 · 对齐主流动作游戏手感）

参考主流大型动作游戏（阿卡姆/战神/只狼/黑神话）的战斗规则，补齐四项核心手感系统：

- **攻击令牌 · 围攻礼让**（`CombatDirector`）：同一时刻只允许 **最多 2 名普通敌人**真正发起
  攻击，其余围绕走位、伺机而动——杜绝被一群敌人同时糊脸的廉价难度，群战更有节奏、可读；
  Boss 不受限（舞台主角）；令牌在一套攻击结束、被打断（硬直/破绽）、死亡、脱战时归还，
  并有超时保险回收
- **待战环走位**（`MaintainStandoff`）：没抢到攻击令牌的敌人只逼近到玩家周围一圈「待战环」
  （攻击距离 +1.8m），太近后撤、太远贴回、在环上绕圈候场——**绝不堆挤进玩家身体**，
  真正做到「一两个进攻、其余围而不攻」，围攻不再是一拥而上的混乱
- **远程只做言语弹幕，不做物理削血**：普通敌人不配置远程物理攻击（近身格斗）；所有 Boss 的
  远程弹幕（法槌标签/凝视光束/引文/追问/硬币「才这点钱」/账单「就这一次」/旧话复读）一律
  **改为纯言语·心理伤害**（去掉远程物理削血），并受凝念能量预算限制——保留「言语攻击弹幕」的
  压迫，去掉不符合大作规则的远程物理弹雨

### 言语攻击只压心神，不扣 HP（本次迭代 · 严格对齐方案「十四言语攻防系统」）

方案明确：敌人言语攻击 →「**玩家心理数值受到影响**」、错误回应「增加反刍/内疚/羞耻」——
**不涉及 HP**。据此全面核对并修正所有言语/感知类攻击，使其只作用于心理数值：

- **纯言语攻击**（台词驱动）：`DoMentalAttack`（凝视/低语 + 三选一言语攻防，本就 `isMentalOnly`）
  与 8 处话语弹幕（标签/凝视光束/引文/追问/硬币/账单/旧话）——全部只压专注/自尊/边界/意志、
  推高反刍/关系消耗，不扣 HP
- **感知/索取型攻击**（此前误扣 HP，本次修正为纯心理）：**凝视扫射**「千目审视」→ 羞耻/自尊；
  **车灯眩光**（外界刺激）→ 专注；**索取冲击**（默认索取型）→ 边界 + 关系消耗
  （举盾明确拒绝仍触发 Boss 大破绽，联动不受影响）
- **保留扣 HP 的只有「动作攻击」**：近战连招、对攻，以及**物理力学 AoE 机制**
  （审判冲击波/自我否定重锤/概念迷环/意义崩桥/责任法槌/内疚落石——预警圈可闪避的物理招式）——
  这些是「动作打动作」，与言语攻击是两条独立路径
- **危险攻击 · 红光警示**（不可格挡）：精英/Boss 有概率使出**危险一击**——头顶亮「危」、
  地面红圈更大更亮、专属警示音、前摇略长给足反应窗口；命中**不可格挡（硬挡会被破防吃满伤）
  ，只能闪避**，教玩家看红光读招而非无脑格挡；伤害/击退加成兑现威胁
- **破韧处决**：敌人被削韧击破进入破绽期时，用**重击/大招**命中触发「**处决**」——
  巨额增伤（×2.8）+ 强顿帧 + 短慢镜 + 能量爆发横幅，把「削韧破防→抓破绽猛攻」
  做成有仪式感的收益循环
- **连段伤害衰减**：连续命中第 7 击起温和递减到最低 0.75 倍（停手 1.5s 复位）——
  正常 4—5 段连招几乎不受影响，只压制长时间锁血的无限连 cheese，鼓励收放有度的连段

### 五种战斗姿态（本次迭代）

把方案「五种姿态」落成战斗层的策略选择——**属性条下方一排五枚姿态**，点选或按 `Tab`/`F` 循环切换：

| 姿态 | 心法 | 克制弱点轴（心理减伤 60% + 言语契合加成） | 物理输出 |
| --- | --- | --- | --- |
| 起步 | 不要想太多，先动起来 | 拖延 / 求职焦虑 / 低信心 | ×1.06 |
| 边界 | 我守住我自己 | 边界冲突 / 公平责任 | ×1.00 |
| 定心 | 外界可以存在，但不能接管我 | 噪声干扰 | ×1.00 |
| 事实 | 发生了什么，先说清楚 | 公平责任 / 求职沉默 | ×1.08 |
| 意志 | 我害怕，但我继续向前 | 意志崩塌 / 羞耻 / 自我怀疑 / 失败恐惧 | ×1.10 |

- **把姿态切到与来袭弱点轴匹配的一档**，这次心理伤害 ×0.4（减 60%）；进攻型姿态（起步/事实/意志）另有物理输出加成
- 与言语攻防联动：正确回击时若**当前姿态正好克制这条轴**，额外回补属性、更快清空反刍（「姿态契合·加成」）
- HUD 高亮当前姿态并显示心法，切换时底部字幕提示核心句

### 责任转嫁法院（终章 · 边界与责任线）

按方案「第四章 边界与责任线 / Demo 关卡四」把整座法院落成一个**自南向北纵深推进**的关卡，
物理空间、地图结构、可交互物体、战斗机制均对齐方案：

- **地图结构（三段式推进）**：法院大门（南墙缺口）→ **文件走廊**（两侧证词走廊/陪审团阴影，
  文件山与锁链闸挡路）→ **责任天平大厅**（责任天平/责任归属台/边界圈）→ **审判席**
  （最高法官台 + 法槌，Boss 在此出现）
- **可交互 / 可破坏物体**：
  - **文件山**：用兵器（**事实之刃**）连击可击碎，露出**事实证据**拾取物（回补心理属性、
    象征"用事实回应而非争对错"）
  - **锁链闸**：横跨走廊，链未断时站入**大幅减速**；劈断任一根锁链即**「破念」**解除束缚
  - **责任天平**：走近即**判断责任归属**——天平从失衡回正，**解锁/确认「责任归还」**并回补边界
  - **边界圈**：安全区，站入缓慢恢复边界、消退「过度负责」
- **责任球机制**：Boss【全责法官】周期性把「责任球」抛向玩家，玩家要**分辨真假**——
  - **红球=虚假责任**：举**边界盾**（格挡键 / 触屏「挡」）当场挡回抛球者削其韧性；
    若不挡任其命中，会附着**「过度负责」**（减速 + 边界流失 + 反刍上升）
  - **绿球=真实责任**：**别推开**，接下它回稳意志；用盾把真实责任推开=推卸本分，掉自尊
- **三件战斗工具**（对齐方案「边界盾 / 责任归还 / 事实之刃」）：
  - **边界盾**＝格挡，当场挡回飞来的责任球
  - **责任归还**＝新技能（技能键 `3` / 触屏「还」）：清除「过度负责」减速、把所有飞来的
    虚假责任球一次性打回法官、回补边界——"把不属于我的部分准确还回去"
  - **事实之刃**＝劈开文件山取证
- **法槌落判**：Boss 近身时在玩家脚下预警红圈后**落槌 AoE**（可翻滚/走出圈外躲开），
  即方案「法槌·Boss 阶段攻击源」
- 与言语攻防联动：法官心理攻击走**边界轴**，最优回击「帮助有边界，这次你自己承担」，
  **边界姿态**正好克制（心理减伤 60% + 契合加成）；战后复盘新增法院四栏
- 入口：主线打通城市广场后，从广场**东侧大门缺口**的传送门进入；「敌人+」面板亦可随处添加
  【全责法官】挑战，个性化画像中「边界/公平责任」高分者遭遇战优先匹配全责法官

### 安全屋系统（本次迭代 · 成长闭环产品化）

右上角「安全屋」枢纽汇总五大子系统（各面板均可独立打开，数据本地持久化）：

- **复盘**：四栏（事实/感受/边界/行动）改为**可编辑输入框**——默认按当前章节生成模板
  （十章各有专属文案），也可改写成自己的话；「归档此战」= 清空反刍 + 回补属性 +
  **写入旧事档案** + **复盘点 +1**（反刍 ≥10 才发点，防刷）
- **成长（技能树）**：五条路线 × 两级共十节点——边界加固/明确拒绝、专注扩容/声音过滤、
  起步惯性/火种常燃、事实之刃锋利/成本判断、自尊锚点/旧事止响；用复盘点解锁、即时生效
  （上限扩容/承伤缩减/冷却缩减/输出增益）
- **装备（五大套装）**：边界守卫套/专注夺回套/公平复盘套/行动起步套/旧我整合套——
  一次穿一套，被动倍率对应各困境线（含方案核心台词）
- **图鉴**：18 种心魔的心理轴、**克制要点**与累计击败数
- **档案**：历史复盘四栏翻页浏览——旧事从脑内回声，变成档案里安静的一页
- **目标板 · 今日唯一目标**（方案核心循环）：从七条成长挑战模板选一条或自己写
  （游戏内挑战/现实行动小任务均可），「钉下目标」后 **HUD 常驻显示**；
  「完成打卡」每日一次 +1 复盘点并恢复行动力——每次进游戏都有明确的小目标；
  独居小屋的目标板物件靠近时提示今日目标状态
- **行动 · 现实行动追踪闭环**（本作核心命题落地）：复盘「行动」栏写下的
  「现实里：去做 X」在归档时**成为一条现实承诺**；下次回安全屋「行动」面板,
  游戏会问「上次你说要做 X,做到了吗?」——**做到 → 复盘点 +2 + 连续行动天数 +1**,
  暂时没做则温和归档不惩罚。把游戏内成长与现实里的一小步真正绑定;隔天未确认
  会有回访提示,安全屋入口挂待确认角标
- **关卡选择 · 传送**（右上角「传送」按钮直达）：全部区域列表 + 解锁状态，
  **当前章节目标区域用 ▶ 高亮**，点击即传送到区域出生点——跨区域章节
  （如第八章回访噪声街区）不再靠走路找入口；章节通关后字幕直接指出下一战场

## 设计原则

- 游戏基于真实经历抽象为敌人原型与场景气氛，**不复刻真实人物/地点/事件**。
- 心理攻击只做成游戏机制（低语/凝视/泥潭+抽象台词），**绝不输出可复制到现实的操控话术**。
- 失败不惩罚：死亡生成复盘任务，引导策略调整后再战，章节进度保留。
- 隐私数据最小化：个人材料与提示词本地保存，支持一键删除。
