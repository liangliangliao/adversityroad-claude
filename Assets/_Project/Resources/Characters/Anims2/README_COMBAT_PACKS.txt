Combat animation packs currently retained in Anims2:

- UAL1_Standard.fbx        : Universal Animation Library 1, standard/in-place
- UAL1_Standard_RM.fbx     : Universal Animation Library 1, root motion
- UAL2_Standard.fbx        : Universal Animation Library 2, standard/in-place
- UAL2_Standard_RM.fbx     : Universal Animation Library 2, root motion

UAL1 and UAL2 are published by Quaternius under CC0 1.0 Universal.
UAL1 includes locomotion, combat, gun actions, sitting, emotes and other general humanoid actions.
UAL2 complements UAL1 with additional melee/armed combos, combo recoveries, parkour and other actions.

These files are stored here as source animation assets only. No runtime mapping or combat-code integration is implied.
